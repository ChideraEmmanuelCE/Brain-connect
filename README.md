# Neon Dodge

A polished responsive browser arcade game built with vanilla HTML, CSS and JavaScript.

## Features
- Keyboard and mobile touch controls
- Progressive difficulty
- Collectible energy orbs
- Local high score
- Pause/resume
- Responsive canvas gameplay
- No frameworks or external assets

## Controls
- **A / D** or **← / →** to move
- **Space** to pause
- Mobile: use the on-screen controls

## Deployment
The included GitHub Actions workflow deploys the game to GitHub Pages whenever changes are pushed to `main`.
